# FFFO – AI i sundhed: fra hudkræft til iltmætning

Komplet materiale til jeres fællesfaglige fokusområde (biologi, fysik/kemi og geografi).
Alt er skrevet, så I kan følge det trin for trin: teori, forsøg, modeller, PowerPoint, plancher og manuskript.

## Overordnet problemformulering

> **Hvordan kan kunstig intelligens (AI) hjælpe med at opdage sygdom og afvigelser i kroppen, og hvem får gavn af det?**

| Fag | Underspørgsmål | Forsøg / model |
|---|---|---|
| Biologi | Hvordan adskiller kræftceller i huden sig fra raske celler, og i hvor høj grad kan AI genkende hudkræft ud fra billeder? | **Liveforsøg:** AI analyserer hudbilleder |
| Fysik | Hvordan måler en pulsoximeter puls og iltmætning ved hjælp af lys, og hvordan kan AI bruge den slags data til at opdage afvigelser? | **Ugeforsøg:** Puls og iltmætning |
| Kemi | Hvordan binder hæmoglobin ilt i blodet, og hvorfor ændrer iltmætningen sig ved fysisk aktivitet? | **Ugeforsøg:** Forklarer jeres resultater |
| Geografi | Hvilke faktorer afgør, om et lands befolkning får gavn af AI i sundhedsvæsenet, og hvad betyder det for kræftdiagnosticering? | **Model + perspektivering** |

## Den røde tråd (det, censor skal kunne se)

1. **Biologi:** Hvad er sygdommen? Kræftceller har ødelagte kontrolmekanismer. Det kan ses på cellerne og på huden.
2. **Fysik:** Hvordan måler vi kroppen med lys? Pulsoximeteret laver data om til tal.
3. **Kemi:** Hvorfor ser tallene ud, som de gør? Hæmoglobin binder ilt kemisk.
4. **Geografi:** Hvem får gavn af teknologien? AI virker ikke lige godt for alle lande eller alle hudtyper.
5. **Fælles konklusion:** AI er et stærkt *hjælpeværktøj*, ikke en læge. Det virker kun så godt som de data, det er trænet på, og som det sundhedssystem, det bruges i.

Bindeleddet mellem alle fag er **data og lys**: AI'en i biologi ser på *billeder* (lys reflekteret fra huden), og pulsoximeteret i fysik måler *lys*, der sendes gennem fingeren. I begge tilfælde skal en algoritme afgøre, om noget er "normalt" eller "afvigende".

## Sådan bruger I filerne

- `.md`-filerne kan læses direkte på GitHub eller i en hvilken som helst editor.
- `.pptx`-filerne kan åbnes i PowerPoint, Keynote eller Google Slides (Filer → Importér). De er lavet som en **start**. Skift billeder ind, og ret teksten til jeres egne resultater.
- `maaleskema.xlsx` kan åbnes i Excel eller Google Sheets. Gule felter er dem, I selv skal udfylde. Resten regnes ud automatisk.

> Tal med jeres lærer om de præcise rammer for jeres prøve (tid pr. gruppe, antal elever, hvad der skal afleveres). Tidsplanen i manuskriptet er sat til ca. 16–18 minutters fremlæggelse og kan nemt forkortes eller forlænges.
